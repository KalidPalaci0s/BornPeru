


## a) Power Supply (Capacidades de suministro de energía)

La solución Bigbelly contará con alimentación solar y una batería recargable para garantizar el funcionamiento de sus componentes electrónicos y del sistema de compactación.

| ID | Requisito |
|---|---|
| PS-01 | La estación contará con un panel solar de 40 W y una batería de 28 Ah para almacenar energía y permitir su funcionamiento durante periodos sin luz solar. |
| PS-02 | El ESP32 utilizará alimentación regulada de 3.3 V, mientras que el sensor HC-SR04 requerirá 5 V DC y una corriente operativa de 15 mA. |
| PS-03 | El DHT22 funcionará entre 3.3 y 5.5 V, el SW-420 entre 3.3 y 5 V y el BH1750 utilizará alimentación de 3.3 o 5 V según su módulo. |
| PS-04 | En Stand-By Mode se reducirá el consumo energético mediante intervalos extendidos de muestreo y funciones de ahorro de energía del ESP32. |
| PS-05 | En Active/Compacting Mode se garantizará alimentación suficiente para los sensores, las comunicaciones y los ciclos de compactación. |
| PS-06 | En Maintenance Mode se mantendrán activos los componentes de diagnóstico y se deshabilitará temporalmente la compactación. |
| PS-07 | En Fault/Risk Mode se priorizará el monitoreo y los indicadores de riesgo, restringiendo las operaciones de compactación. |

## b) Time-Delay (Restricciones de tiempo)

El sistema debe cumplir con restricciones temporales para garantizar una adquisición adecuada de las mediciones y una respuesta rápida ante condiciones de riesgo.

| ID | Requisito | Tiempo |
|---|---|---|
| TD-01 | El DHT22 respetará el intervalo mínimo entre mediciones de temperatura y humedad. | 2 segundos |
| TD-02 | El HC-SR04 utilizará un pulso de activación de 10 µs y un intervalo entre mediciones de al menos 60 ms. | 10 µs / 60 ms |
| TD-03 | El BH1750 completará las mediciones en modo de alta resolución. | Aproximadamente 120 ms |
| TD-04 | En Active Mode se actualizarán periódicamente las mediciones de los sensores. | Cada 2 segundos |
| TD-05 | En Stand-By Mode se extenderá el intervalo de muestreo ambiental para reducir el consumo energético. | Cada 60 segundos |
| TD-06 | Ante una condición crítica detectada, se restringirá localmente la compactación y se activará Fault/Risk Mode. | Máximo 1 segundo |
| TD-07 | La BSCU actualizará el thresholdLed después de recibir thresholdLedState del Edge Connector. | Máximo 1 segundo |
| TD-08 | Se enviará telemetría al Edge Connector mediante POST /data-records. | Cada 10 segundos en Active y 5 minutos en Stand-By |
| TD-09 | Al ingresar a Maintenance Mode se deshabilitará la compactación. | Máximo 1 segundo |

## Sustento

Los requisitos permiten equilibrar la eficiencia energética y la capacidad de respuesta de las estaciones Bigbelly.

El sistema reduce el consumo energético durante Stand-By y aumenta la frecuencia de monitoreo durante Active Mode. Asimismo, garantiza que las condiciones críticas sean atendidas localmente y que el Edge Connector proporcione la información necesaria para controlar el indicador de riesgo.
