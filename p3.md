## a) Definición de usuarios finales

Se identifican cuatro tipos de usuarios para la plataforma Bigbelly:

| Usuario | Aplicación | Función |
|---|---|---|
| Personal de recolección | CLEAN Mobile | Consulta estaciones, recibe alertas y registra recolecciones. |
| Administradores municipales | Bigbelly Web Management | Supervisa estaciones, configura umbrales y gestiona rutas. |
| Soporte técnico | Bigbelly Web Management | Diagnostica fallas y gestiona mantenimientos. |
| Personal CRM | Bigbelly Web Management | Administra clientes, contratos e incidencias comerciales. |

## b) Definición del número y tipos de servicios

Se proponen **12 servicios funcionales**, distribuidos en 3 servicios por cada tipo de usuario.

| Usuario | Servicio | Tipo |
|---|---|---|
| Personal de recolección | 1. Consulta de estaciones y alertas | Monitoreo |
| | 2. Gestión de recolecciones | Operacional |
| | 3. Reporte de incidencias | Registro |
| Administradores municipales | 4. Monitoreo de estaciones | Monitoreo |
| | 5. Configuración de umbrales | Configuración |
| | 6. Planificación de rutas | Planificación |
| Soporte técnico | 7. Monitoreo de alarmas | Monitoreo |
| | 8. Diagnóstico de dispositivos | Diagnóstico |
| | 9. Gestión de mantenimiento | Mantenimiento |
| Personal CRM | 10. Gestión de clientes y contratos | Administración |
| | 11. Atención de incidencias | Soporte |
| | 12. Programas de sostenibilidad | Gestión comercial |

## c) Definición de necesidades de información integrada

Para implementar los servicios definidos, se requiere integrar información de los sensores IoT y de los sistemas de gestión de Bigbelly.

| Servicio | Información integrada necesaria |
|---|---|
| 1. Consulta de estaciones y alertas | Ubicación, porcentaje de llenado, estado de estación y alertas. |
| 2. Gestión de recolecciones | Rutas, estaciones asignadas, fechas y estados de recolección. |
| 3. Reporte de incidencias | Estación, ubicación, tipo de incidencia y descripción. |
| 4. Monitoreo de estaciones | Temperatura, humedad, llenado, vibración, iluminación y estado operativo. |
| 5. Configuración de umbrales | Límites de temperatura y llenado, condiciones de riesgo y reglas de notificación. |
| 6. Planificación de rutas | Ubicaciones, niveles de llenado y recolecciones pendientes. |
| 7. Monitoreo de alarmas | Alertas, vibraciones detectadas, modo Fault/Risk y estado de riesgo. |
| 8. Diagnóstico de dispositivos | Lecturas de sensores, modo de operación y estado del compactador. |
| 9. Gestión de mantenimiento | Estación afectada, fallas, técnico asignado e historial de intervenciones. |
| 10. Gestión de clientes y contratos | Clientes, organizaciones, estaciones asociadas, contratos y pagos. |
| 11. Atención de incidencias | Tickets, clientes asociados, descripción y estado de atención. |
| 12. Programas de sostenibilidad | Campañas, clientes participantes y estadísticas de recolección. |
